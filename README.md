# Hospital Patient Care Analytics – SQL Project

## 📌 Project Overview

This project analyzes hospital patient care and operational data using SQL.
The goal is to generate useful insights about patients, departments, treatments,
admissions, and hospital operations.

## 🎯 Objectives

- Analyze patient and hospital data
- Identify important healthcare KPIs
- Analyze patient admissions and treatments
- Understand department-wise performance
- Generate business insights using SQL queries

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 📊 Key Analysis

The project includes SQL queries for:

- Patient analysis
- Department-wise analysis
- Admission analysis
- Treatment analysis
- Doctor/department performance
- Patient outcomes
- Hospital operational KPIs

## 🔑 SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- INNER JOIN
- LEFT JOIN
- Aggregate Functions
- CASE statements
- Subqueries
- CTEs
- Window Functions

## 📁 Project Files

- `Hospital_Patient_Care_Analytics.sql` – SQL queries
- `Hospital_Patient_Care_Analytics.pptx` – Project presentation

## 📈 Key Insights

The SQL analysis helps identify patterns in patient admissions,
department performance, treatments, and hospital operations.
